# 未マージPRを採点へ反映するための調査

調査日は2026年8月10日です。
2026年5月10日から8月10日までにVOICEVOX Organizationの公開かつ非アーカイブな30リポジトリで動いたPRを、GitHub APIで取得して調べました。
マージ済み146件と、期間内に作成または期間内にクローズされた未マージ35件が対象です。

## 現状の非対称

未マージPRは取得段階で除外されています。
PR検索が`is:pr is:merged`に限定されているため、オープンPRとクローズ済み未マージPRは採点用データに入らず、作者もレビュー者も点を得ません。

一方でIssueは状態を問わず取得され、未解決でも点が入ります。
未解決Issueは、参加者が2人以上、参加者が1人以上かつ証拠が2種類以上、添付または測定結果あり、のいずれかを満たすと状態点1を得ます。
解決済みの状態点2に対して半分です。

同じ未完了でも、Issueは他者の関与があれば評価され、PRは何も評価されません。
PRを出してレビューを受けている途中の作業と、そのレビュー作業自体が、どちらも見えていません。

放置された古いPRが点を得続ける状況は起きていません。

## 状態係数の検討

実装枠は重要度の65%です。
ここへ状態係数を掛けたときの増分を計算しました。
現行の人物向け実装枠の合計は307.90点です。

| オープン | クローズ済み | 増分 | 現行比 |
| ---: | ---: | ---: | ---: |
| 1.00 | 0.50 | 36.88点 | 12.0% |
| 0.50 | 0.25 | 18.44点 | 6.0% |
| 0.25 | 0.125 | 9.22点 | 3.0% |

採用するのはオープン0.5倍、クローズ済み0.25倍です。
未解決Issueの状態点が解決済みの半分であることと、証拠のあるnot_planned Issueがさらに半分であることに揃えました。
新しい根拠を持ち込まず、既存の未完了の扱いと同じ比率になります。

1.0倍では、マージ済みより変更行が3倍近い未マージPRがそのまま加算され、増分が12%に達します。
0.25倍では、レビューを受けている最中の作業が実質的に見えないままです。

## レビュー保証を必須にする理由

実装枠には既にレビュー保証係数があります。
作者以外の承認、実質的レビュー、独立した人間によるマージのいずれかがあれば全量、なければ50%です。

未マージPRでは、このいずれもない場合に実装枠を配分しません。
マージされていないコードの価値は、他者が関与した事実でしか裏付けられないためです。
未解決Issueが他者の関与なしには状態点を得られないことと同じ考え方です。

50%を配分する場合、ドラフト11件だけで11.62点が生まれます。
レビュー保証ありの35件全体が生む18.44点に匹敵する量が、誰も見ていない変更から発生します。
配分しない場合、ドラフトは自然に0点になり、ドラフトを特別扱いする条件が要りません。

## レビュー枠には状態係数を掛けない

レビュー枠は重要度の20%で、期間内のレビュー活動に応じて配分されます。
未マージPRでも、この枠は割り引きません。

レビューの労力はPRがマージされるかどうかに左右されません。
問題のある変更を止めた場合も作業量は同じで、割り引くとレビュー者が結論によって減点されます。
増分は6.40点で、現行のレビュー枠合計35.66点に対して18.0%です。

レビュー枠は元から実際のレビュー活動の量で決まるため、活動がなければ0のままです。

## 関連Issue枠は配分しない

重要度の15%は関連Issueの枠です。
未マージPRにはこの枠を配分せず、未配分にします。

関連Issueにマージ済みPRがなければ、そのIssueは独立Issueとして別に採点されます。
未マージPRにも15%を配分すると、同じIssueの働きを二重に数えます。
独立Issueの判定は今までどおりマージ済みPRの関連Issueだけを除外し、未マージPRの関連Issueは独立Issueのまま残します。

同じ理由で、未マージPRは他のPRとワークストリームへまとめず、1件ずつ独立したワークストリームとして扱います。
まとめるとマージ済みPRの重要度が未マージPRの変更行で膨らみ、作者以外の点数が動いてしまいます。

## 期間の扱い

PRは期間末時点の状態で判定します。
マージ日が期間末より後のPRは、その期間ではまだオープンです。
現在closedでも期間末より後にクローズされたIssueをopenとして扱う既存の判定と揃えました。

配点の対象になる日は状態ごとに一つです。
マージ済みはマージ日、クローズ済みはクローズ日、オープンは作成日です。
どの期間でも一つのPRが二重に数えられません。

レビュー枠だけは、対象の日が期間外でも期間内にレビュー活動があれば配分します。
オープンPRの滞留は中央値28.9日あり、既定の集計期間は7日です。
作成日だけを条件にすると、大半のオープンPRへのレビューが評価されません。
